This is a sample writing post. Posts in the `_posts` directory with the `writing` category will automatically appear on your Writing page.

## How to Create Writing Posts

1. Create a new markdown file in the `_posts` directory with the naming convention: `YYYY-MM-DD-title.md`
2. Add the front matter (metadata) at the top:
   - `layout: post` (required)
   - `title: "Your Title"` (required)
   - `categories: writing` (required - this makes it appear on the writing page)
   - `author: "Your Name"` (optional)
   - `tags: [tag1, tag2]` (optional)
   - `image: filename.jpg` (optional - if you have a featured image)

3. Add your content in markdown below the front matter

## Features

- Posts automatically appear chronologically on the Writing page
- Each post gets its own individual page with the post layout
- Post metadata (date, author, read time) is automatically displayed
- Images, links, and all markdown formatting is supported

## Example Structure

```
_posts/
├── 2024-01-15-sample-writing.md
├── 2024-01-14-another-post.md
└── 2024-01-13-more-writing.md
```
